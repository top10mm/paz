### 📱 Kit Paz - Anticrises

O **Kit Paz - Anticrises** é um aplicativo web projetado para oferecer suporte e ferramentas práticas em momentos de crise, combinando uma interface intuitiva, áudios e músicas internas selecionadas para proporcionar tranquilidade e foco. 

🚀 **Acesse o aplicativo rodando em:** [https://top10mm.github.io/paz/](https://top10mm.github.io/paz/) 

### 🎯 Sobre o Projeto

Este aplicativo foi desenvolvido com o objetivo de centralizar recursos acessíveis de áudio e música em uma experiência web leve e rápida, que pode ser executada direto do navegador, tanto no computador quanto no celular. 

* **Músicas do Aplicativo:** Trilhas sonoras geradas por meio de Inteligência Artificial, otimizadas para relaxamento e foco.
* **Áudios de Suporte:** Conteúdo cedido e autorizado diretamente para este projeto (conforme detalhado na seção "Sobre" do aplicativo).
